Revit Sheets -> DWG  (Revit 2024, 2025, 2026, 2027)

Суулгах:
  1. Revit-ийг хаана.
  2. Zip-ийг задлаад install.bat-ийг ажиллуулна.
     Компьютерт суусан Revit 2024-2027 бүрт автоматаар суулгана.
  3. Revit-ийг нээхэд Add-Ins табд "Sheets -> DWG" самбар гарна:
       Sheets -> Layouts      - sheet бүр AutoCAD-ийн тусдаа layout болно (Revit-ийн export шиг)
       Sheets -> Model space  - бүх sheet model space-д блок болж зэрэгцэн байрлана

Шаардлага:
  - Revit 2024, 2025, 2026 эсвэл 2027
  - AutoCAD суусан байх (accoreconsole.exe ашиглана).
    AutoCAD 2020-2024 болон 2025-аас хойших хувилбарын аль алиныг дэмжинэ;
    хоёулаа суусан бол цонхонд AutoCAD Core Console-ийн замыг сонгож болно.

Хавтсууд:
  Revit2024 ... Revit2027   - Revit-ийн хувилбар бүрийн файлууд
  RevitSheetsToDwg\acad2025 - AutoCAD 2025+ (.NET 8)-д зориулсан хувилбар

Устгах:
  %APPDATA%\Autodesk\Revit\Addins\<он>\RevitSheetsToDwg.addin болон
  RevitSheetsToDwg хавтсыг устгана.
